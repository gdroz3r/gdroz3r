## 🧑‍💻 About Me

I'm a security engineer with **hands-on experience** spanning the full security stack — from traditional Web2 application security (Web, Mobile, API, CEX platforms) to deep Web3 protocol audits across the EVM, Solana, Cosmos, TON, NEAR, ICP, Aptos, Fuel, and Canton ecosystems.

I've audited bridges, perpetuals, AMMs, stablecoin issuance protocols, LSTs, lending markets, oracles, launchpads, and full appchains — and I build my own tooling to make audits faster and more rigorous.
